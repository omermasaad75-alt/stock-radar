# رادار — نظام مسح وتحليل أسهم البيني ستوك (تلقائي بالكامل)

نظام تلقائي كامل: اكتشاف الأسهم المرشحة نفسه (من غير ما تدخل أي رمز) + تحليل
فني كامل + فلترة حسب استراتيجية "التقسيم العكسي" و"الموجة الثانية" — كل ده
بمصادر مجانية بالكامل.

## المصادر المستخدمة (كلها مجانية)

| البيانات | المصدر |
|---|---|
| اكتشاف الأسهم المقسّمة عكسيًا (بدون إدخال رموز) | BusinessQuant corporate actions API |
| الأسعار / الشموع / التقسيمات / الفلوت / القيمة السوقية / الشورت / الأخبار | yfinance (مجاني، بدون مفتاح API) |

## هيكل المشروع

```
.
├── .github/workflows/scan.yml       # يشغّل الاكتشاف + المسح تلقائيًا كل 30 دقيقة
├── scripts/discover_splits.py       # اكتشاف تلقائي للتقسيمات العكسية (BusinessQuant)
├── scripts/scanner.py               # التحليل والفلترة الكاملة (yfinance)
├── scripts/requirements.txt
├── watchlist.json                   # اختياري — لإضافة رموز يدويًا (خصوصًا نموذج الموجة الثانية)
├── reverse_split_candidates.json    # ناتج discover_splits.py (يتحدث تلقائيًا)
├── docs/
│   ├── index.html                   # الداشبورد (تفتحه GitHub Pages تلقائيًا)
│   └── data.json                    # نتائج آخر عملية مسح (يتحدث تلقائيًا)
└── README.md
```

## كيف يشتغل النظام (تلقائيًا بالكامل)

1. `discover_splits.py` يسأل BusinessQuant: "أي الأسهم عملت تقسيم عكسي خلال
   آخر 20-50 يوم؟" ويكتب القائمة في `reverse_split_candidates.json` — بدون
   أي إدخال يدوي منك.
2. `scanner.py` يقرأ القائمة دي + أي إضافات يدوية من `watchlist.json`،
   ويسحب لكل سهم شموعه وبياناته من yfinance، يحسب كل المؤشرات، يطبّق الشروط
   السبعة ونموذج الدخول، ويكتب النتيجة في `docs/data.json`.
3. الداشبورد (`docs/index.html`) يقرأ `data.json` مباشرة ويعرض كل سهم في
   قائمته الصحيحة (جاهزة / شبه جاهزة / متابعة / مرصودة / مستبعدة).

كل ده يتكرر تلقائيًا كل 30 دقيقة عبر GitHub Actions — من غير ما تلمس حاجة.

## خطوات التفعيل (مرة واحدة بس)

1. **ارفع الملفات دي على مستودعك** بنفس هيكل المجلدات أعلاه.

2. **أضف Secret واحد بس:**
   Settings → Secrets and variables → Actions → New repository secret
   الاسم: `BUSINESSQUANT_API_KEY` — نفس المفتاح اللي شغال معاك في مستودعك التاني.
   (مفيش حاجة تانية محتاجة — yfinance مايحتاجش مفتاح API خالص).

3. **فعّل GitHub Pages:**
   Settings → Pages → Source: Deploy from a branch → Branch: `main` / `docs` → Save.

4. **شغّل أول عملية مسح يدويًا:**
   تبويب Actions → Stock Scanner → Run workflow.
   بعد ما يخلص، افتح رابط الداشبورد — المفروض تشوف النتائج جاهزة تلقائيًا.

5. **(اختياري)** لو عايز تتابع سهم معيّن يدويًا برضو (خصوصًا لنموذج الموجة
   الثانية اللي BusinessQuant ما يكتشفهوش)، ضيفه في `watchlist.json`:
   ```json
   { "symbol": "ABCD", "model_hint": "spike" }
   ```

## تعديل جدولة المسح

الافتراضي: **كل ساعة**، تغطية كاملة لكل جلسات التداول — Pre-market و Market
و Afterhours (من ~4 صباحًا حتى ~8-9 مساءً بتوقيت شرق أمريكا، أيام الأسبوع).
هذا مهم خصوصًا لأن أغلب صعودات نموذج الموجة الثانية بتحصل بعد الإغلاق
(Afterhours) حسب الاستراتيجية.

فيه سطرين `cron` في `.github/workflows/scan.yml` مش سطر واحد — عشان التغطية
تلف من آخر اليوم UTC لأول اليوم اللي بعده (فرق التوقيت الأمريكي عن UTC).
لو عايز مسح أسرع من مرة كل ساعة، غيّر `0 8-23` إلى `*/30 8-23` (كل 30 دقيقة)
في السطرين الاتنين مع بعض.

## محدوديات مهمة (اقرأها قبل ما تعتمد على النظام بالكامل)

- **BusinessQuant** يكتشف التقسيمات العكسية فقط — مفيش مصدر مجاني موثوق حاليًا
  لاكتشاف "كل الأسهم اللي صعدت 100%+ اليوم" تلقائيًا لنموذج الموجة الثانية،
  فده لسه محتاج إضافة يدوية في `watchlist.json` (أو مصدر بيانات إضافي لاحقًا).
- **الشورت من yfinance مش لحظي** — Yahoo يحدّثه من تقارير FINRA كل أسبوعين
  تقريبًا، فممكن يكون متأخر كذا يوم عن الواقع. أفضل من عدم وجوده، لكن راجعه
  يدويًا لحظة القرار النهائي.
- **الفلوت** أفضل تقدير متاح من yfinance (floatShares أو sharesOutstanding
  كبديل) — مش دايمًا دقيق 100٪ للشركات الصغيرة جدًا.
- **فلترة الأخبار السلبية** كلمات مفتاحية بسيطة (offering, dilution...) في
  عناوين آخر أخبار yfinance — تقريبية، مش تحليل دلالي كامل.
- **الدعم / الاختراق / إعادة الاختبار / الشمعة الساقطة** قواعد مبسّطة
  (Heuristics) على الشموع اليومية — مرشح أولي يوفر وقت الفحص اليدوي، مش قرار
  دخول نهائي بحد ذاته.
- **yfinance غير رسمي** (يعتمد على واجهة Yahoo Finance الداخلية) وممكن
  يتعطل أو يتغيّر أحيانًا بدون إشعار مسبق — لو المسح فشل فجأة على أغلب
  الأسهم، جرّب تاني بعد شوية غالبًا مشكلة مؤقتة من عند Yahoo.

## التجربة محليًا (اختياري)

```bash
cd scripts
pip install -r requirements.txt
export BUSINESSQUANT_API_KEY=مفتاحك_هنا
python discover_splits.py
python scanner.py
```
هيكتب النتيجة في `../docs/data.json` — افتح `docs/index.html` في المتصفح
مباشرة لمعاينتها قبل رفعها لـGitHub.
