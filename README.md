# رادار التقسيم العكسي — أسهم الارتكاز الخاملة

طرفية عربية RTL لرصد **التقسيم العكسي → الهبوط والتشبع البيعي → ارتكاز الدعم → اختبار المقاومة → إعادة الاختبار → الاختراق**، مع طبقة مستقلة لكشف السيولة التجميعية وCMF والانحراف الإيجابي والسلبي.

تصميم الطرفية مكيّف من [OMERMASAAD/reverse-split-radar V2](https://github.com/OMERMASAAD/reverse-split-radar)، ومخصص لاستراتيجية هذا المستودع، لا لاستراتيجية قنص الذعر اللحظي في المرجع.

> أداة بحث ورصد، وليست توصية استثمارية أو منصة تنفيذ. التصنيفات والأهداف آلية وغير مختبرة تاريخيًا. لا توجد نتائج أرباح أو محفظة حقيقية.

## الواجهة

- بطاقات للجاهزية والارتكاز والتجميع والانحراف، وقمع المسح الأصلي.
- بحث بالرمز/الشركة، فلاتر المرحلة، الجاهزية، القاعدة الخاملة، سحب السيولة، والانحراف الإيجابي/السلبي أو البيانات الناقصة.
- جدول قابل للترتيب، وبطاقات متجاوبة للجوال، وتصدير CSV يشمل حالة توفر البيانات.
- درج تحليل السهم: CMF(20/10)، MFI(14)، جودة القاعدة، قائمة الشروط، الأخبار، ومستويات المخاطرة الورقية.
- شموع يومية و4 ساعات عند توفرها، EMA20/30/50 وVWAP، حجم فعلي، ولوحات CMF/MFI/RSI/OBV/MACD.
- خطوط الانحراف على السعر والمؤشرات المتوافقة، باستخدام **قيم وإحداثيات الشموع نفسها**؛ لا تُرسم خطوط CMF إذا كانت الإشارة مدعومة بـMFI فقط.
- تبويبات ملخص التحليل والمنهجية وتشخيص المسح. ` / ` للبحث و`Esc` لإغلاق الدرج.
- وضع **داكن / فاتح** من الشريط العلوي أو داخل درج السهم، مع حفظ الاختيار ومشاركته مع صفحة الإعدادات. لوحتا ألوان مستقلتان للنصوص والجدول والشارات والشموع والمؤشرات؛ التبديل لا يعيد ضبط الفلاتر أو الفريم أو التقريب.
- PWA بذاكرة محدودة: ملف واحد للبيانات، ووضع دون اتصال يعلن أن اللقطة محفوظة.

## البيانات الحالية — تنبيه مهم

اللقطة القديمة كانت تحفظ **OHLC فقط دون الحجم**. لذلك لا يمكن إعادة بناء CMF أو MFI أو OBV منها، ولا من الفلوت أو متوسط الحجم. ترقية الملف:

- تحفظ الأسعار، وقت مسح السوق، المرحلة، درجة الجاهزية، الأخبار، والمستويات الأصلية.
- تحسب التحليل السعري الممكن من الشموع المتاحة.
- تضع مؤشرات الحجم والانحراف في حالة **غير متاحة** (`null` / `unavailable`)، لا «صفر» أو «محايد».
- لا تُنشئ أحجامًا اصطناعية أو قراءات 4H مشتقة من اليومي.
- تفصل `updated_at` (وقت مسح السوق) عن `analysis.recalculated_at` (وقت إعادة الحساب).
- تميّز التصنيف بأنه مبدئي إذا كانت بعض التأكيدات مجهولة.

**المسح التالي بالنسخة الجديدة عبر GitHub Actions** يجلب OHLCV الفعلية ويملأ المؤشرات. تشغيله يجب أن يكون على فرع يحتوي الكود الجديد. البيئة المحلية تحتاج اتصالًا فعليًا بـYahoo Finance وNasdaqTrader؛ إعادة الحساب دون شبكة لا تجلب أسعارًا جديدة.

## المؤشرات والمنهجية

### CMF القياسي، دون تغيير تعريفه

```text
MFM / CLV = (2 × Close − High − Low) / (High − Low)
MFV       = MFM × Volume
CMF(n)    = SUM(MFV, n) / SUM(Volume, n)
```

الشمعة المسطحة (`High == Low`) تعطي مضاعفًا صفرًا. الفترتان 20 و10 منفصلتان؛ لا يُعرض خليط منهما باسم CMF(20). يلزم اكتمال النافذة، ولا يُستبدل الحجم المفقود بحجم تقديري أو بحجم يوم آخر. صفر الحجم الفعلي يُحفظ كما هو؛ مجموع حجم صفري لا يعطي CMF قابلًا للقياس.

- **MFI(14):** تدفق السعر النموذجي `(H+L+C)/3` موزونًا بالحجم، موجبًا/سالبًا حسب تغير السعر النموذجي. نطاقه 0–100.
- **OBV:** حجم تراكمي حسب تغير الإغلاق؛ أصل السلسلة صفر. **A/D:** تراكم `CLV × الحجم`.
- **VWAP:** تراكمي ومثبت عند التقسيم عندما يتوفر التاريخ، دون معايرة قسرية إلى قيمة أخرى.
- «صافي التدفق» هو وكيل `CLV × الحجم`، **ليس** تدفق أوامر شراء/بيع ولا إثباتًا لدخول مؤسسات.
- قيم الإحماء المفقودة تبقى مفقودة؛ لا تُملأ من شموع مستقبلية. الحساب يسبق اختصار التاريخ إلى 90 يوميًا / 96 شمعة 4H للعرض.

### كشف الانحراف

- قيعان/قمم محلية تؤكدها شمعتان على كل جانب؛ فصل ≥ 4 شموع، ضمن آخر 40 شمعة، وآخر نقطة ليست أقدم من 12 شمعة.
- **إيجابي:** قاع أدنى/مزدوج (تسامح 1.5%) مع ارتفاع CMF ≥ 0.04 أو MFI ≥ 5 نقاط أو تحسن OBV ≥ نصف متوسط حجم الفترة.
- **سلبي:** قمة أعلى/مزدوجة بالتسامح نفسه مع تراجع المؤشرات بالقيم نفسها. هبوط السعر والسيولة معًا **ليس** انحرافًا سلبيًا.
- **تجميع خفي:** مقارنة منفصلة في قاعدة 8 شموع ضيقة (≤12%) قرب الدعم (≤12%)، تغير السعر المطلق ≤3%، وتحسن CMF ≥0.06 إلى قراءة موجبة.
- الوصف «قوي» يعني توافق مؤشرين أو أكثر، وليس احتمال ربح أو تأكيد انعكاس. تُحفظ النقاط والتواريخ والأسعار والقراءات والفروق والتفسير في `liquidity.divergence`.

### الارتكاز والتصنيف

القاعدة الخاملة تتطلب ثباتًا ≥5 جلسات، نطاق آخر 10 شموع ≤15%، بقاء الإغلاق قرب الدعم، وعدم كسره بأكثر من التسامح. تظهر ضيق القاعدة، انكماش التذبذب، لمسات الدعم، جفاف الحجم عند توفره، والقاع المزدوج/الأعلى المحتمل.

**الجاهزية الأصلية** = مجموع الشروط التسعة /100. المرحلة لا تتغير بسبب طبقة السيولة. التصنيف المركب = 70% جاهزية + 30% تأكيد، بحدود A+≥82، A≥68، B≥52، C≥38، ثم D. الحالات المجهولة لا تُحتسب ناجحة ولا يُعاد تطبيع وزنها إلى 100؛ يُعرض `grade_provisional` و`confirmation_available_weight`.

```text

docs/index.html                 # صفحة GitHub Pages الرئيسية
docs/terminal.css, terminal.js   # تصميم الطرفية والتفاعل والرسم
docs/theme.js                   # تفضيل المظهر المشترك قبل تحميل CSS
docs/data.json                  # نتيجة المسح للواجهة
docs/manifest.json, sw.js       # PWA
tests/test_analytics.py         # تحقق الصيغ والفجوات والمنطق
tools/verify_dashboard.mjs      # تحقق DOM/الفلاتر/الدرج/Canvas/CSV
```

`reverse_split_candidates.json` و`watchlist.json` ملفات قديمة لا تقود المسح الحالي. لإضافة رموز للسوق اكتب كل رمز في سطر في `extra_tickers.txt` (اختياري). لا تستخدم النسخة الحالية BusinessQuant أو مفتاح API.

## التشغيل المحلي

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python3 scanner.py               # مسح حقيقي؛ يحتاج Yahoo/NasdaqTrader
python3 scanner.py --enrich      # إعادة حساب الملف المحفوظ فقط دون شبكة
python3 -m http.server 8080 --bind 0.0.0.0 --directory docs
```

افتح `http://localhost:8080` محليًا؛ على Arena استخدم رابط **Live Preview**. الواجهة تستعمل عناوين نسبية على نفس المصدر، ولا تتصل بخادم localhost داخل متصفح المستخدم.

للترقية من ملف آخر: `python3 scanner.py --enrich --input snapshot.json`. يمكن إضافة `--metadata names.json` لأسماء شركات محفوظة؛ **لا** يُستعمل متوسط حجم من هذا الملف لإعادة بناء أحجام تاريخية.

## الاختبارات

```bash
python3 -m unittest discover -s tests -v
npm ci
npm run check
```

تتحقق اختبارات Python من الصيغ بمقارنات يدوية، الإحماء، الأحجام الناقصة/الصفرية، عدم استخدام المستقبل، الانحراف في الاتجاهين، استقلال 4H، الحجم الورقي المحدود برأس المال، وتطابق ملفي النتائج. يتحقق JSDOM من التفاعل والرسم وCSV والتوافق مع اللقطة القديمة وأخطاء الاتصال وXSS، وتبديل المظهر وحفظه ورفض التخزين، وإعادة رسم الشارت دون تغيير حالته. تشمل الاختبارات تباين النصوص ≥ 4.5:1 والعناصر البيانية المهمة ≥ 3:1 في الوضعين. أمثلة الإشارة الإيجابية/السلبية **اصطناعية ومعلّمة بوضوح داخل الاختبارات**، ولا تُضاف إلى قائمة الأسهم المنشورة.

عند تعديل `docs/index.html` شغّل `npm run sync` لمزامنة صفحة الجذر.

## GitHub Actions وPages

- Pages: نشر الفرع `main` من المجلد `/docs`، بعد مراجعة ودمج التغييرات.
- Actions → `scan` → Run workflow يشغّل مسحًا يدويًا بالنسخة الموجودة على الفرع المختار.
- الجدولة الحالية: 07:23، 11:41، 14:53، 18:17، 21:37 **UTC**، أيام الاثنين–الجمعة. قد يتأخر GitHub أو يُسقط تشغيلًا؛ التشغيل المجدول يُتخطى إذا كان آخر ملف أحدث من 5 ساعات.
- زر «تحديث النتائج» والتحديث التلقائي كل 60 ثانية يعيدان قراءة الملف، **لا** يطلقان مسحًا جديدًا.
- عند انعدام بيانات الشبكة أو فشل جميع المرشحين، لا يستبدل الماسح اللقطة القديمة بقائمة فارغة ناجحة.

## الحدود والمخاطر

Yahoo مصدر غير رسمي وقد يتأخر أو يفشل؛ لا توجد أسعار لحظية. الفلوت قد يُستبدل بالأسهم القائمة ويُعلّم بعلامة ≈. فحص الأخبار كلمات مفتاحية فقط، ولا يضمن اكتشاف جميع مخاطر التخفيف أو الإفلاس. مستويات الدعم والاختراق قواعد تقريبية. المؤشرات على تاريخ سعري قصير قد تختلف عن المسح الكامل ويُعلن ذلك. أسهم التقسيم العكسي عالية المخاطر، والوقف الورقي لا يضمن تنفيذًا عند الفجوات.
